## 112

Thermal comfort
This section describes the thermal comfort criteria for the different spaces and
activities in a school. It uses the comfort category descriptions from BS EN 15251,
see Table 7-1. Note that a space may have different comfort categories for different
thermal comfort criteria. For example a sports hall has a category IV for cold
draughts (see Table 7-3) but a category III for the summertime overheating risk
assessment (see table 7.9).
Standards for all aspects of thermal comfort are set out in BS EN ISO 15251
