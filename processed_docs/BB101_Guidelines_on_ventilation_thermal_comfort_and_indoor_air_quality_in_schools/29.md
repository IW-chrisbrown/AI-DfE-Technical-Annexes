In science and design and technology practical spaces with only Type A appliances,
it is relatively simple to use a CO2 monitoring and interlock system.
See section 2.9.2.
For Type A appliances, a common extract duct from extraction canopies can be used
with a wall mounted CO2 interlock system as IGEM UP 19 requires the ventilation
system to be interlocked and must be in operation before gas is available to cookers.
For Type B appliances, a wall mounted CO2 interlock can be used with a common
extract duct from extraction canopies but only as a secondary interlock and not as
the primary main interlock which should be as described in IGEM UP 19.
