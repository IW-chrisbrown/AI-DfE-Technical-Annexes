## 6.3 Documentation
6.3.1 Documentation shall be provided as set out in the DfE’s EIR which includes a
simple user-friendly Building User Guide including details of all user controls to be
provided. [PM_10_20_28]
6.3.2 Schematics of each electrical and alarm system shall be provided adjacent to the
main panels. [PM_40_40_75]
6.4 Commissioning and Building Performance Evaluation
6.4.1 A programme for commissioning shall be provided as set out in the DfE’s EIR.
