## SYSTEM REQUIREMENT

Heating circuits –
Weather compensation
- Centralised control from heat source/boiler control panel
either optimiser or time clock control with automatic daylight-
saving correction (BST/GMT changeover).
- Boiler control should be weather compensated as well as
based on spaces served e.g.,  if all AHUs or thermostats
indicate no heat required then heating boiler and pumps
should turn off.
