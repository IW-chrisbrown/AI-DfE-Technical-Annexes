## 9.3.   Calculation Reports
9.3.1 As detailed in the DfE’s EIR, an electric lighting and daylighting calculation
report/drawing shall be provided in order to demonstrate compliance with the performance
criteria for all spaces. [PM_10_20_28]
9.3.2 A single calculation can be used to validate multiple spaces where the results can be
meaningfully extrapolated. [PM_40_30_20]
